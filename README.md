# NovaCatálogo — Prototipo visual académico

Primer avance del sistema web de catálogo y administración de productos. Vue 3 + Vite, con datos locales de demostración. **No hay todavía Backend Laravel, base de datos, autenticación real, compras ni persistencia.**

## Ejecutar

1. Instalar Node.js 20 o superior.
2. En esta carpeta: `npm install`
3. Ejecutar `npm run dev`
4. Abrir la dirección local indicada por Vite.

## Funcionalidades de demostración
- Catálogo público responsivo con búsqueda, categorías y paginación.
- Detalle de producto.
- Panel administrativo visual con resumen, tabla y edición temporal en memoria.
- Datos de ejemplo que se restablecen al recargar.
